# BookMart SQL Database Project

BookMart is a MySQL database project for practicing SQL queries.
The project represents a simple online bookstore system.
It contains authors, books, and sales-related information.
The database includes three main tables: authors, books, and sales.
The authors table stores author names, countries, birth years, and mentors.
The books table stores titles, genres, prices, ratings, and publication years.
The sales table stores quantities, dates, cities, and customer types.
The project contains 10 authors, 25 books, and 40 sales records.
It demonstrates primary keys and foreign key relationships.
The dataset is designed for SQL learning and database practice.
It covers INNER JOIN, LEFT JOIN, RIGHT JOIN, and SELF JOIN.
It also includes CROSS JOIN and FULL OUTER JOIN using UNION.
Set operations such as UNION are demonstrated with real examples.
Anti-join queries are used to find books without sales.
Subqueries are used for averages, filtering, and comparisons.
EXISTS and NOT EXISTS queries are included.
Window functions such as RANK and ROW_NUMBER are demonstrated.
LAG is used to compare quantities between consecutive sales.
Running totals are calculated using SUM with window functions.
Common Table Expressions are created using the WITH clause.
Revenue and total sales quantity are calculated for analysis.
The project also demonstrates debugging common MySQL errors.
This database is useful for students learning SQL and DBMS concepts.
